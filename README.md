# sequence timer

タイマーの開始方法を色々と設定できるタイマーアプリです。複数のタイマーをバー表示で管理できます。PCブラウザ・スマホブラウザ両対応、オフライン動作可能です。

## デモ

GitHub Pages で公開中です。
https://adeged3lf.github.io/Sequence-timer/


スマホ版Chromeで、設定（三点）→「ホーム画面に追加」することで、ホーム画面に追加できます。
一旦ホーム画面に追加すれば、オフラインでも使えるはずです。

## 主な機能

### タイマーの追加
- 「＋追加」ボタンを押して、タイマーを追加してください

### タイマーの種類

- **残り時間タイマー** — 指定した時間からカウントダウン
- **時刻タイマー** — 指定した時刻までの残り時間を表示。翌日以降も繰り返し発火
- **時計** — 現在時刻を表示するクロックバー

### タイムバー

- スロット全体がバーになっており、残り時間が減るにつれてバーが縮む
- ベースカラー・色の閾値（残り○秒を切ったら○色）を自由に設定
- タイトルと残り時間を重ねて表示

### アラーム

- **全画面アラーム** — タイマーのベースカラーで背景が点滅、タイトルを大きく表示
- **タイムバー点滅** — スロット全体が点滅
- 残り0秒に加えて、残り○秒前にも追加アラームを設定可能
- 複数の全画面アラームが重なった場合は優先度順（並び順）に順番に表示

### 連携機能（詳細設定）

- 開始トリガー：手動・指定時刻・他タイマーの終了・他アラームのON/OFF
- 一時停止・再開トリガー：ボタン操作に加えて他タイマーのアラーム・一時停止と連動
- 循環参照チェック：設定時にエラーを通知

### その他

- ドラッグ＆ドロップで並び替え（優先度変更）
- シンプル設定 / 詳細設定の切り替え
- 文字の明るさをアプリ内で調整可能
- JSON形式で設定をエクスポート・インポート

## 設定の保存

設定はブラウザの localStorage に自動保存されます。ブラウザを閉じても次回起動時に復元されます。

デバイス間で設定を共有するには、画面上部の「保存」ボタンでJSONファイルをエクスポートし、別のデバイスで「読込」ボタンからインポートしてください。←作者にはよく分からないのでＡＩか何かに聞いて調べてください

> ブラウザの「閲覧データを削除」でサイトデータまで消去すると設定が失われます。定期的にJSONエクスポートしてバックアップすることをおすすめします。
